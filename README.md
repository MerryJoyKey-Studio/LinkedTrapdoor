# LinkedTrapdoors

A Hytale mod that synchronizes adjacent trapdoors. When you open or close one trapdoor, all connected trapdoors do the same.

Crouch to interact with a single trapdoor without affecting neighbors.

## Installation

1. Build the mod: `gradlew build`
2. Copy `build/libs/LinkedTrapdoors-1.0.0.jar` to your Hytale mods folder

Mods folder location:
```
%APPDATA%\Hytale\install\release\UserData\Mods
```

## Requirements

- Hytale (January 2026 release or later)
- Java 21

## Building

```
gradlew build
```

The compiled JAR will be in `build/libs/`.
